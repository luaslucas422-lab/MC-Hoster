Server Recovery

MC Hoster keeps a small .mh file for each server (unless you turned it off when you set it up). It remembers the server's settings, player lists, plugins and each world's level.dat.

Repair a server in MC Hoster

  1. Double-click the .mh file, or open MC Hoster and click Server Recovery… on the Server tab.
  2. MC Hoster shows what's wrong. Click Repair.
  3. It puts back broken settings and lists, downloads the server and plugins again, fixes a broken level.dat, and brings the world back from the newest backup if it's gone. Broken files are kept in a folder, never deleted.

Recovery files are in the server folder and in %APPDATA%\MC Hoster\recovery, so they survive even if the server folder is deleted.

Read a recovery file here

No MC Hoster on this PC? Open a .mh file here to see what's in it and download the server's files. It's read in your browser; nothing is uploaded.
