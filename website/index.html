Host a Minecraft server from your own PC.

Pick a server type and a version, press Finish. MC Hoster downloads everything, opens your router, adds anti-cheat and gives you the address to send to friends.

Download for Windows Update logs

Free. Windows 10 or 11. No Java or setup needed, MC Hoster gets what it needs.

Everything a home server needs

Paper, Purpur, Spigot, Fabric, Bedrock

Java versions from 1.20.6 to the newest, and Bedrock. Versions are listed live.

Gh0st AC anti-cheat

Bundled and on by default: fly, speed, reach, aura and more are caught and punished.

Friends can join

Opens your router ports by itself, finds your IP, and can point your own domain at it.

Plugins in one click

Twelve ready presets plus search of Modrinth, Hangar and CurseForge, and your own folders.

Safe by default

Auto restart, auto start on a schedule, backups, and a Max storage usage limit that stops the server before your drive fills up.

Updates itself

Shows what's new and installs the update. Your servers keep working.

From download to playing

  1. Open MC Hoster. Read the terms and tell it your name and Minecraft username. You are made operator on your servers.
  2. Pick a server type and version, name it, set the max players and press Finish.
  3. Press Start. When it says online, copy the address from the Play tab and send it to friends.

Made for MC Hoster and free with it. Add them in tab 5, they work together.

Questions

Is it free?

Yes. MC Hoster and the Dark plugins are free.

Is my PC safe to use as a server?

Opening a server to the internet has risks. Only use plugins and mods from official sites, and keep backups of worlds you care about.

Windows says it's unknown software.

MC Hoster isn't signed yet. Click More info, then Run anyway, or get it only from this page or the GitHub releases.

Is it made by Mojang?

No. It's an independent hobby project and isn't connected to Mojang or Microsoft.
